# Barra 类型股票风险模型：原理、边界与合成校验

**定位：** 本文解释公开的多因子风险模型原理，不复现 MSCI 商业 CNE5/CNE6，也不把本项目的 CH-4 时间序列回归称作 Barra 风险模型。MSCI 的[CNE5 公开说明](https://www.msci.com/documents/10199/2935796a-0a80-4050-934a-12966d1e2518)提及中国本地股票、行业及风格风险因子；MSCI 的[中国 A 股 CNE6 研究讨论](https://www.msci.com/research-and-insights/blog-post/vive-la-difference-active-factor-strategies-in-china-a-shares)说明另有不同版本。具体暴露定义、数据历史、估计和调整方法属于各商业产品的专有实现，不能从这份通用数学框架推断。

## 1. 从证券收益到风险协方差

对同一时点的 N 只股票，设 **X** 为 N×K 暴露矩阵：每行是一只股票，每列为市场、风格或行业风险因子。规模、价值、动量、波动率等可作为风格暴露；行业虚拟变量描述业务类别。模型形式是 `r = X f + ε`。风险模型通常用同期股票横截面收益估计因子收益 **f**，再从历史因子收益估计 K×K 因子协方差 **F**，并估计个股特异风险协方差 **D**（简化实现常取对角）。最后得到证券收益风险矩阵 **Σ = X F Xᵀ + D**。

只要 F、D 对称半正定，Σ 也对称半正定，因为任意权重向量 a 有 `aᵀΣa = (Xᵀa)ᵀF(Xᵀa) + aᵀDa ≥ 0`。若个股权重为 w，预测组合方差是 `wᵀΣw`；相对于基准 b 的主动风险/跟踪误差是 `sqrt((w−b)ᵀΣ(w−b))`。行业中性要求组合与基准的行业暴露差受约束；风格中性约束如规模或价值的暴露差。两者都不等于“风险为零”，也不自动提高 Alpha。

**风险预测与 Alpha 预测分工不同。** 风险模型估计条件波动、相关和风险来源，Alpha 模型试图预测未来期望收益。即使某风险因子在历史中收益为正，风险暴露也不能单独证明未来超额收益。本项目的 CH-4 是对**组合时间序列超额收益**进行事后四因子回归；它没有逐股 X、逐日横截面因子收益、F 和 D，因此不构成 Barra 类型风险系统。

## 2. 可运行的合成示例

`factor_neutralization_v191.synthetic_barra_risk_example()` 使用三只虚构证券及两个抽象因子：

```text
X = [[1,-1], [1,0], [1,1]]
F = [[0.0004,0.0001], [0.0001,0.0009]]
D = diag(0.0001,0.00015,0.0002)
w = [0.5,0.3,0.2]，b = [0.3,0.3,0.4]
Sigma = X @ F @ X.T + D
```

程序算得组合日波动率约 **2.162%**、相对基准日跟踪误差约 **1.249%**、Σ 最小特征值约 **0.0001495**。单元测试直接核对矩阵乘积、对称性、最小特征值非负，以及组合与主动组合波动率为实数。所有数值均为人工设置、日频方差单位；它们不是 A 股实测风险，也不包含商业 Barra 数据。

## 3. 研究中容易失效的地方

- **数据时间穿越：** 用今天的行业或市值解释历史持仓，会把未来信息带入 X。行业应有生效/失效日，市值须有观测时点；财报变量还需披露可用日。
- **极端暴露与共线性：** 规模和行业可能高度相关；一个行业只剩极少证券时横截面因子收益不稳。检查条件数、样本覆盖、因子收益跳变和异常值，不能只看回归是否运行成功。
- **F、D 估计误差：** 短窗口会有噪声，长窗口会落后于波动状态切换；停牌、退市和公司行动会污染收益。协方差可能数值上不对称或非半正定，需要独立验证与合理修正，不能在报告中隐藏。
- **预测检验：** 比较事前预测跟踪误差与后续实现波动，分时段报告低估和高估；极端行情下检查行业/风格集中与流动性假设。优化组合对风险估计误差尤其敏感。
