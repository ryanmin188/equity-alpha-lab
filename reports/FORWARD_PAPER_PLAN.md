# 向前模拟：已有工具与尚未取得的证据

`scripts/equity_alpha_v2/paper_journal.py` 是本地事件账本，支持带日期的订单、独立成交记录、撤单和估值。**未连接券商，也没有向前模拟收益。** 下单事件不会自动变成成交。历史回测结果不写入这份账本冒充未来业绩。

已实现：单股5%下单限额、现金预留、同日买入不可卖出、拒绝重复事件、报价日期核对、2%成交价格容差、15%回撤停止新增买单，以及可重放的哈希链。订单按当日有效处理，未成交部分需撤单；初始资金不能在重放时改变。哈希链帮助发现文件修改，不能替代外部时间戳或券商证明。

当前仅适合单进程人工验证，未实现实时行情订阅、交易所日历校验、科创板特殊手数、券商成交导入、分红送转处理、对账告警、数据库并发保护和订单自动发送。因此它是下一步工程基础，不是生产交易系统。股票需使用真实未复权价格和原始股数，不能直接粘贴回测的复权单位。

## 不含行情的示例

保存以下JSON为被Git忽略的 `outputs/paper/order.json`。`FAKE` 是虚构证券，日期仅是格式示例；这不是实际交易建议或已发生订单。

```json
{"id":"demo-order-1","kind":"order","date":"2026-10-15","quote_date":"2026-10-15","quotes":{"FAKE":10.0},"symbol":"FAKE","side":"BUY","quantity":100}
```

```powershell
python scripts/equity_alpha_v2/paper_journal.py --journal outputs/paper/demo.jsonl --event outputs/paper/order.json
python scripts/equity_alpha_v2/paper_journal.py --journal outputs/paper/demo.jsonl
```

结果应只有待成交订单，现金仍为100万元，持仓为空。单元测试覆盖这一点。若要验证成交记录格式，使用另一个事件文件：

```json
{"id":"demo-fill-1","kind":"fill","date":"2026-10-15","quote_date":"2026-10-15","quotes":{"FAKE":10.0},"order_id":"demo-order-1","quantity":100,"price":10.0,"fee":5.0}
```

执行同样的 `--event` 命令后，现金应为998995元、持仓100股；重复事件应被拒绝。所有示例都是人工数据，不能用于计算所谓实盘胜率。

## 下一阶段如何取得有效证据

1. 冻结本次版本，从未来实际交易日开始保存信号产生时刻、可用行情快照、订单与成交来源，不回填历史日期。
2. 先完成独立原始价格、公司行动和持仓对账，再开发冻结模型的实时信号导出与券商模拟账户适配。
3. 使用券商提供的真实模拟成交回报，记录拒单、延迟与滑点，按日对账。没有成交就保留未成交，不以收盘价假定成交。
4. 持续记录足够长的样本，比较同期可投资基准与费用；不因数周盈利就推断长期有效。此处未设置任何自动交易或未来运行任务。
