# 发布前方法审核

审核日期：2026-10-14（Asia/Shanghai）。结论：**可作为历史量化研究作品展示；不可作为已验证盈利策略或实盘系统展示。**

## 证据与验证范围

核对了六个研究脚本、V1–V1.5输出及公开仓库。使用现存 Python 3.12.5 研究环境与本地Qlib数据，在独立目录顺序重跑六个脚本，全部完成。月度面板、逐股预测、组合回测、交易记录、持仓记录与原版本SHA-256完全一致。V1.1及V1.5内部记账检查为0失败；3项人工数据测试通过。[机器可读记录](REPRODUCTION_CHECKS.json)

此核验不是全新环境安装、第三方数据审计或独立策略验证。参数与数据未改变，因此重复得到相同结果不能增加市场有效性的统计证据。

## 与七步工作流的对应

| 环节 | 评价 | 证据或缺口 |
|---|---|---|
| 数据处理 | 已实现研究级处理 | `historical_membership`、`snapshot`读取历史区间、限定信号日之前数据，做1%/99%截尾及横截面标准化；没有独立原始数据审计 |
| 因子构建 | 已实现8项量价因子 | 含IC、十分组和冗余分析；无基本面数据、行业中性化或真实多期限衰减检验 |
| 策略搭建 | 已实现 | EqualFactor/Ridge/LightGBM × Top30/Buffer30_60 |
| 模型训练 | 部分符合严格验证标准 | 最多48个月回看、最少24个月训练；`exit_date <= decision_date`过滤标签；没有隔离的验证集选参与未触碰最终测试集 |
| 分层回测 | 已实现研究层次，执行层不完整 | 因子诊断和扣费账户分开；5bp单边费用、拒单与陈旧估值；没有可执行价格、涨跌停、手数、完整税费和冲击模型 |
| 策略优化 | 初步敏感性研究 | 缓冲规则、年份、成本场景比较；没有宽参数稳定平台，也没有完整场景重放 |
| 实盘风控 | 尚未实现 | 风险指标是事后分析；没有券商接口、订单状态闭环、事前限额、实时告警或紧急停止 |

原帖中的“模型机械决策实现长期稳定收益”不是由这七个步骤必然推出的结果。深度学习也不是合格研究流程的必备项；能解释简单模型、验证其增量价值，比仅增加模型复杂度更重要。

## 具体发现

| 重要性 | 观察及定位 | 对结论的影响 | 建议 |
|---|---|---|---|
| 高 | `run_research.py::TEST_START`及旧报告已声明2017–2020被开发过程观察 | 逐月预测在时序上样本外，但研究设计选择不独立 | 冻结因子、参数及评价规则，再使用未参与研究的区间；选参须嵌套在历史训练/验证内部 |
| 高 | `risk_attribution.csv`：所有组合累计收益16.36%–27.98%，基准39.66%；全部IR为负，市场模型alpha点估计为负 | 不能宣传“跑赢指数”或“已验证正alpha”；不显著也不等于证明没有任何效应 | 首页并列基准、回撤与不确定性，保留负结果 |
| 高 | `simulate`用复权开盘价、分数股、先卖后买，并按同一开盘价确定目标股数 | 内部记账自洽不能证明开盘集合竞价可按该数量和价格成交；真实公司行动未核对 | 加真实价格与分红/拆股处理、开盘下单时点和撮合约束 |
| 高 | 固定5bp双向对称费用；无单独滑点、税费、市场冲击或资金容量模型 | “扣费”不是“实盘级精细回测” | 按市场和日期适用的实际费用/交易规则建模并重放账户 |
| 中 | `snapshot`中的 `vol.shift(1).iloc[-21:-1]` | 实际均量窗口为t−21至t−2，跳过t−1；仅用历史信息，但不是常见t−20至t−1定义 | 当前版如实说明；若调整，版本化并重跑，不能保留原分数 |
| 中 | `snapshot`中波动、振幅等滚动统计允许部分缺失，尚无统一最少有效观测数；起始时点无额外预热区间 | 不同股票/时期有效窗口可能不同，早期60日因子出现缺失 | 明确最小观测覆盖、预热与样本诊断，检验结果敏感性 |
| 中 | `calculate_deciles`先剔除缺失结果再分组；IC也仅使用有标签股票 | 491条缺失结果不影响预测资格，但诊断组别受可观测样本影响 | 在全体事前合格证券上定组，再单独报告组内标签缺失比例与偏差敏感性 |
| 中 | `performance`与`drawdown_details`只用月度账户收益 | 月频回撤可能漏掉月内更深下跌 | 真实风险评估应增加逐日或更细估值 |
| 中 | `cost_sensitivity`沿用已生成收益与交易路径 | 只是固定路径近似；不同成本可能改变现金和持仓 | 后续逐场景重跑完整账户 |
| 中 | 成分区间来自Qlib；回归只控制市场收益；多次因子/模型比较未做多重检验修正 | 不能确认公告可得时点、独立风格alpha或事前显著性 | 核对供应商快照；加入行业/规模等暴露；事前定义主要假设 |
| 低 | 旧README链接指向未上传的outputs，未展示基准；代码与报告根目录平铺 | 面试官不易阅读，复现路径混乱 | 已整理目录、补充README图表、基准、数据要求及测试 |

“预先指定因子符号”在源码中是一条注释，能确认本次重跑固定使用该符号，不能据此证明研究开始前已登记、没有经历过选择。没有找到完整实验登记记录，故保留探索性定位。

## 面试可展示的优势

可以具体讲清数据时点、标签成熟、模型比较、分组诊断与可交易收益的差别；能从正绝对收益追问基准和市场暴露；能解释拒单、陈旧估值、末期清算和成本近似。它体现的是研究能力与诚实判断，不依赖包装一个漂亮收益率。

下一轮优先级：冻结方案和新测试区间 → 核对价格与公司行动 → 完善执行和成本 → 风格中性与增量检验 → 向前模拟及实时风控。任何新结果都应与当前历史版本分开保留。
